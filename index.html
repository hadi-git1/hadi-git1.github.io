BUNKR: Offline Password Manager

A local-first, privacy-focused desktop password manager (Python + PySide6) built as my MSc dissertation. Every vault is encrypted with AES-GCM or ChaCha20-Poly1305, keys are derived via PBKDF2-HMAC-SHA256 (100k iterations, unique salt per vault), and PIN/recovery answers are hashed with Argon2id. No network calls happen at any point. Includes duplicate/near-duplicate password detection, clipboard auto-clear, idle auto-lock, encrypted import/export, and live encryption-method migration.

  • SQLite
  • AES-GCM
  • PBKDF2
